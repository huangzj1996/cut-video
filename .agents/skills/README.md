# Superpowers 项目级技能

本目录只保留此仓库使用的三个 Superpowers 技能，不修改用户全局技能：

- `writing-plans`：多步骤或跨模块需求的任务拆解；基于上游技能裁剪，不强制 TDD、逐步提交、工作树、子代理或单独保存计划文件。
- `verification-before-completion`：完成前根据实际检查结果核实声明。
- `receiving-code-review`：收到审查意见后先验证问题，再决定修改方式。

来源：[obra/superpowers](https://github.com/obra/superpowers)，上游提交 `5bf4e78011075bcfc0dc295f0724994cd123ee71`。`writing-plans` 为项目级改编，其余两个技能保留上游内容。许可证见 [LICENSE.superpowers](LICENSE.superpowers)。

触发条件及开发人员确认流程以仓库根目录的 `AGENTS.md` 为准。更新上游内容时，核对本仓库的技能裁剪和确认流程，避免重新引入强制 TDD 或完整 Superpowers 工作流。
